## 1. ESTRUCTURA DE CUENTA

```
Leo Muebles — Cuenta Meta Ads
│
├── CAMPAÑA 1: [FRÍA] Captación de Nuevos Clientes
│   ├── Ad Set 1A — Carmen (Mamás 34-45)
│   ├── Ad Set 1B — Miguel (Jóvenes 22-35)
│   └── Ad Set 1C — Roberto (Profesionales 35-55)
│
└── CAMPAÑA 2: [CALIENTE] Retargeting
    ├── Ad Set 2A — Interacciones IG/FB (últimos 30 días)
    └── Ad Set 2B — Mensajeros previos WhatsApp (últimos 60 días)
```

### Configuración de Campañas

| Parámetro | Campaña 1 (Fría) | Campaña 2 (Retargeting) |
|-----------|-----------------|------------------------|
| **Objetivo** | Mensajes → WhatsApp | Mensajes → WhatsApp |
| **Presupuesto base/mes** | $130 | $40 |
| **Presupuesto diario normal** | $4.00 | $1.33 |
| **Días de quincena (14-16, 29-31)** | $8-10/día | $4/día |
| **CBO activado** | Sí (Meta distribuye entre ad sets) | No (piso mínimo manual) |

> **Por qué objetivo "Mensajes" y no "Tráfico":** Meta optimiza para personas que hacen clic en botones de WhatsApp. Con tráfico llegan bots y curiosos. Para Leo Muebles, donde el 100% de ventas pasa por WhatsApp, Mensajes es la única opción correcta.

## 4. ESTRATEGIA DE COPY

### Fórmula AIDA para Leo Muebles en RD
| Etapa | Ejemplo |
|-------|---------|
| **A — Atención** | "¿Todavía comprando muebles sin garantía?" |
| **I — Interés** | "Muchos dominicanos pagan de más por muebles que duran 2 años..." |

### Palabras que Disparan Conversión en RD
| ✅ Usar | ❌ Evitar |
|---------|---------|
| "Cuotas" / "a plazos" | "Contáctenos" |
| "Sin banco" / "financiamiento directo" | "Adquiera" |
| "Sin trámites" | "Garantizamos" (sin especificar) |
| "Te lo llevamos" / "entrega a domicilio" | "Alta calidad" (cliché) |
| "Garantía" | "Precios increíbles" |
| "Escríbenos" | "Somos líderes" |
| "Cuotas desde RD$XXX/mes" | "Financiamiento disponible" (vago) |

### Política de Precio en Ads
- **Carmen y Miguel:** Mostrar precio siempre. Si parece alto, presentar en cuotas ("RD$28,500" → "desde RD$950/mes")
- **Roberto:** No precio en imagen. Mencionar "asesoría personalizada". El precio llega en WhatsApp.

### Cómo Hacer el Boost de Quincena
1. **Manual (recomendado):** Entrar al Ads Manager el día 13, subir presupuesto. El día 17, bajarlo. 2 minutos.
2. **Reglas automáticas de Meta (gratis):** Ads Manager → Reglas automáticas → Aumentar 150% en días 14-15-16, bajar el 17.

### Bidding
- **Estrategia:** "Volumen más alto" (bid automático) — no usar bid manual con <$200/mes
- **Cuándo escalar:** Si costo/conversación < RD$500 ($8.50 USD) por 2 semanas → subir 20% presupuesto (máximo 30% a la vez)
- **Cuándo pausar:** CTR <0.5% tras 2,000 impresiones | CPC >$0.80 sin conversaciones | Frecuencia >3.5

| **Costo/conversación WA** | $3–12 USD | **<$8 USD** | >$15 USD |
| Frecuencia (audiencia fría) | — | 1.5–3.0 | >3.5 |

### Cálculo de ROAS Mínimo Aceptable
```
Ticket promedio = RD$25,000 (~$425 USD)
Costo por conversación = $8 USD
Tasa de cierre = 20%
→ Costo por cliente = $8 / 0.20 = $40 USD
→ ROAS = $425 / $40 = 10.6x
→ ROI (con margen 40%) = ($170 - $40) / $40 = 3.25x ✅
```

### Cómo Trackear sin Píxel Web
1. UTM en link WhatsApp del anuncio: `https://wa.me/18091234567?text=Hola,%20vi%20su%20anuncio%20en%20Facebook`
2. Preguntar al cliente al inicio: "¿Cómo nos contactaste?"
3. Registro semanal: número de chats nuevos vs. semana anterior
4. Etiquetas en WhatsApp Business: marcar "vino de ad Facebook" / "vino de ad Instagram"

2. ¿Cuál es el ticket promedio de venta y el margen bruto? (para calcular CPA objetivo real)
3. ¿WhatsApp Business conectado a Meta Business Suite? (permite Custom Audiences de mensajeros)
4. ¿Cuenta de Instagram con 90+ días de antigüedad y posts regulares? (retargeting IG funciona mejor con cuenta establecida)

6. ¿Zonas de entrega definidas? (si solo SDQ, refinar geo para no desperdiciar presupuesto)
7. ¿Existe catálogo en Meta Commerce? (permite Dynamic Ads automáticos)
