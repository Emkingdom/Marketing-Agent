🦁 Conceptos de Modernización del Logo

Tres propuestas que evolucionan el león actual hacia un diseño moderno. El Concepto C es el recomendado por versatilidad y bajo costo de implementación.

Concepto A — Minimalista
León geométrico en azul noche + dorado. Ideal para web, apps y papelería corporativa. Fuente: Montserrat Black.
Concepto B — Bold & Energético
Impacto máximo para vallas, anuncios digitales y materiales de oferta. Fuente: Barlow Condensed ExtraBold.
Concepto C — Moderno Familiar ⭐
León amigable y redondeado. Mantiene calidez del original, elimina lo rígido. Funciona en todos los canales. Fuente: Nunito ExtraBold (gratuita en Google Fonts).
💡 Instrucciones para el diseñador: Usar el Concepto C como base. León redondeado (no angular), 3-4 colores máximo (#F5A623, #1A3A5C, #D64045, #FFD580). Fuente: Nunito ExtraBold para "LEO", Nunito Light o SemiBold para "MUEBLES". Entregar en SVG + PNG transparente (mínimo 1000px) + versión dark (blanco sobre fondo oscuro).
